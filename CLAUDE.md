# ZYNEX — Project Rules

> Also read `AGENTS.md` — this Next.js version has breaking API changes vs. older
> training data; it points to the bundled docs in `node_modules/next/dist/docs/`.

ZYNEX is an AI-powered product studio (UAE-based, serving globally). This repo is the
official marketing site + admin dashboard. AI designs/builds websites, portals, web apps,
mobile apps, dashboards and AI agents for clients, shipping in days not months.

Target clients: small businesses, startups, enterprises. English only.

## Tech Stack (do not deviate)

- Next.js (latest, App Router) + TypeScript
- Tailwind CSS + shadcn/ui (install components via shadcn MCP, never hand-roll)
- Motion (motion.dev / Framer Motion successor) for UI animation
- Three.js via React Three Fiber + @react-three/drei for 3D scenes
- Lenis for smooth scrolling
- Supabase (Postgres + Auth + Storage) — leads, blog, portfolio, chat logs
- Vercel AI SDK for the chatbot, provider-agnostic (swap via env vars)
- Zod for form/schema validation
- Deploy target: Vercel

## Tools to use while building

## Brand & Design Tokens

Dark, futuristic, premium — not a generic SaaS template. Glassmorphism panels, subtle
film grain, glowing borders, animated gradients used sparingly (accents/CTAs, not full
backgrounds).

**Color tokens** (CSS variables + Tailwind theme, defined in `app/globals.css` /
`tailwind.config.ts`; values below are the working proposal — flag if you want changes):

| Token | Value | Use |
|---|---|---|
| `--background` | `#07080B` | base canvas, near-black with cool undertone |
| `--surface` | `#0E1016` | panels/cards (glass over this) |
| `--surface-glass` | `rgba(14,16,22,0.55)` + blur | glass panels |
| `--foreground` | `#F4F6FA` | primary text |
| `--muted` | `#8B93A7` | secondary text |
| `--border` | `rgba(255,255,255,0.08)` | hairlines, glowing on hover |
| `--accent` | `#3D6BFF` | electric blue/indigo — primary CTA, links, glow |
| `--accent-2` | `#C6FF3E` | neon lime — secondary accent, sparingly (highlights, chips, chart accents) |
| `--danger` | `#FF5C5C` | errors |
| `--success` | `#3EFFB0` | success states |

Radii: `--radius-sm: 8px`, `--radius-md: 14px`, `--radius-lg: 24px`.
Shadows: soft ambient shadow + colored glow shadow variant using `--accent` at low opacity.

**Typography** (Google Fonts):
- Display: **Space Grotesk** (headings, sharp/geometric)
- Body: **Inter** (clean sans, body/UI text)

**Motion language:**
- Interactive hero: WebGL particle-network field reacting to cursor
  (components/canvas — raw WebGL, not R3F; see note below)
- Scroll-driven reveals (Motion `useScroll`/`whileInView`)
- Magnetic buttons, text scramble/split-text headings on hero + section titles
- Animated gradient accents on borders/CTAs, page transitions between routes

**3D/perf rules:**
- Lazy-load all 3D (dynamic import, `ssr: false`), pause render loop when canvas is
  off-screen (IntersectionObserver), cap `pixelRatio` at 2
- Static fallback (poster image or CSS gradient) on low-power devices and when
  `prefers-reduced-motion` is set
- Targets: Lighthouse Performance 85+, Accessibility/SEO 95+
- Mobile-first, fully responsive

## Workflow

1. CLAUDE.md (this file) first — done.
2. Short build plan → wait for explicit approval before writing code — approved.
3. Build order, commit after each stage:
   a. setup + design system
   b. layout, nav, footer
   c. home page with 3D hero
   d. remaining marketing pages
   e. quote builder + booking + WhatsApp
   f. chatbot
   g. admin dashboard
   h. SEO + performance pass
4. Subagents: at most 2 concurrent, only for clearly separable work (e.g. admin
   dashboard vs. Playwright visual QA). Everything else stays in the main session.
5. After each stage: Playwright visual check (1440px + 390px) + `npm run build`; fix all
   errors/type issues before moving to the next stage.
6. `.env.example` lists every var with a comment. No secrets in code or commits.
7. Final deliverable includes a README: setup, Supabase connection, chatbot provider
   config, Vercel deploy steps.
